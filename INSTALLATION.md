# AlbOS Installation Guide\n\n## Minimum Requirements\n\n- **Device:** Samsung Galaxy S5 (SM-G900F/G900H/G900I/G900P/etc.)\n- **RAM:** 2GB minimum\n- **Storage:** 16GB internal storage minimum\n- **Bootloader:** Unlocked\n- **Recovery:** TWRP (Team Win Recovery Project) installed\n- **USB Debugging:** Enabled\n- **PC/Laptop:** Windows, macOS, or Linux with ADB and Fastboot\n- **Battery:** At least 50% charge\n\n## Prerequisites\n\n### 1. Install ADB and Fastboot\n\n**Windows:**\n- Download Android SDK Platform Tools from [Google](https://developer.android.com/tools/releases/platform-tools)\n- Extract to a folder (e.g., `C:\\platform-tools`)\n- Add to PATH or use terminal in that folder\n\n**macOS:**\n```bash\nbrew install android-platform-tools\n```\n\n**Linux:**\n```bash\nsudo apt-get install android-tools-adb android-tools-fastboot\n```\n\n### 2. Enable USB Debugging on Samsung S5\n\n1. Go to `Settings > About Phone`\n2. Tap \"Build Number\" 7 times to enable Developer Mode\n3. Go to `Settings > Developer Options`\n4. Enable \"USB Debugging\"\n5. Enable \"OEM Unlocking\" (if available)\n\n### 3. Unlock Bootloader\n\n**WARNING: This will wipe all data on your device!**\n\n```bash\n# Connect device via USB\nadb devices\n\n# Reboot to bootloader\nadb reboot bootloader\n\n# Unlock bootloader (requires confirmation on device)\nfastboot flashing unlock\n\n# Confirm on device when prompted\n```\n\n### 4. Install TWRP Recovery\n\n1. Download TWRP for Samsung S5 from [twrp.me](https://twrp.me)\n2. Save as `twrp-s5.img` in your platform-tools folder\n\n```bash\n# Device should still be in bootloader mode\nfastboot flash recovery twrp-s5.img\n\n# Boot into TWRP\nfastboot reboot recovery\n```\n\n## Installation Steps\n\n### Step 1: Download AlbOS ROM\n\n- Download the latest AlbOS build from Releases (when available)\n- Place `albos-*.zip` on your PC\n\n### Step 2: Download GApps Package\n\n- Download ARM GApps for Android 12 from [opengapps.org](https://opengapps.org)\n- Select: Platform: ARM, Android: 12.0, Variant: Pico/Nano/Micro\n- Place `open_gapps-arm-12.0-*.zip` on your PC\n\n### Step 3: Transfer Files to Device\n\n```bash\n# Connect device via USB (should be in Android or recovery)\nadb push albos-*.zip /sdcard/\nadb push open_gapps-arm-12.0-*.zip /sdcard/\n```\n\n### Step 4: Boot into TWRP Recovery\n\n```bash\n# Reboot to TWRP\nadb reboot recovery\n```\n\nOr manually:\n- Power off device\n- Hold: Volume Up + Home + Power\n- Select \"Recovery\" mode\n\n### Step 5: Wipe Data (IMPORTANT!)\n\nIn TWRP Recovery:\n1. Tap **Wipe**\n2. Tap **Format Data**\n3. Type \"yes\" to confirm\n4. Tap **Cache** and wipe\n5. Go back\n\n### Step 6: Install AlbOS ROM\n\nIn TWRP Recovery:\n1. Tap **Install**\n2. Navigate to `/sdcard/`\n3. Select `albos-*.zip`\n4. Swipe to confirm flash\n5. Wait for installation to complete\n\n### Step 7: Install GApps\n\nIn TWRP Recovery (do NOT reboot yet):\n1. Tap **Install**\n2. Navigate to `/sdcard/`\n3. Select `open_gapps-arm-12.0-*.zip`\n4. Swipe to confirm flash\n5. Wait for installation to complete\n\n### Step 8: Reboot System\n\nIn TWRP Recovery:\n1. Tap **Reboot**\n2. Select **System**\n3. Wait for first boot (may take 5-10 minutes)\n\n## First Boot\n\n1. Device will boot into AlbOS Setup Wizard (light mode)\n2. Follow the 5-step setup:\n   - Welcome\n   - Wi-Fi Connection\n   - Google Account\n   - Security & Privacy\n   - Completion\n3. After setup, device is ready to use\n\n## Troubleshooting\n\n### Device stuck on boot logo\n- Wait 10-15 minutes (first boot is slow)\n- If still stuck, boot back to TWRP and check logs:\n  - TWRP > Advanced > View Logs\n\n### Cannot flash ROM\n- Ensure TWRP is installed correctly\n- Try flashing with ADB sideload:\n  ```bash\n  adb sideload albos-*.zip\n  ```\n\n### USB not recognized\n- Install Samsung USB drivers\n- Try different USB port\n- Try different USB cable\n\n### Bootloader won't unlock\n- Check if device is in bootloader mode: `fastboot devices`\n- Some carriers may prevent bootloader unlock\n\n### GApps installation fails\n- Ensure you downloaded correct variant (ARM, Android 12.0)\n- Try Nano or Pico variant (smaller size)\n- Ensure enough storage space before installing\n\n## Uninstall / Return to Stock\n\n1. Download stock Samsung ROM for S5\n2. Use Odin on Windows or Heimdall on Linux/macOS\n3. Flash stock recovery\n4. Re-lock bootloader (if desired):\n   ```bash\n   fastboot flashing lock\n   ```\n\n## Support\n\n- Report issues on GitHub Issues\n- Check XDA Developers for S5 custom ROM guides\n- TWRP support: https://twrp.me\n\n## Disclaimer\n\n**Installing custom ROMs voids warranty and carries risks:**\n- Potential device brick (though recovery is possible with TWRP)\n- Loss of all data (recommended: backup first)\n- Loss of warranty from Samsung\n- Potential security vulnerabilities if from untrusted sources\n\n**Use at your own risk!**\n"
