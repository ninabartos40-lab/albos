# AlbOS

AlbOS este un concept de ROM custom pentru Samsung Galaxy S5, cu interfață dark minimală și aspect Android 12 / One UI-inspired.

## Ce este inclus

- tema dark completă
- mockup pentru aplicația Settings
- mockup pentru tastatură
- paletă de culori și stiluri de bază
- structură pregătită pentru extensie Android

## Structură

```text
app/
  src/
    main/
      res/
        drawable/
        layout/
        values/
```

## Tema principală

- dark background
- accent blue
- iconuri Google Material style
- controls cu rounded corners
- design modern, minimalist

## Fișiere UI create

- `app/src/main/res/layout/settings_activity.xml`
- `app/src/main/res/layout/keyboard_activity.xml`
- `app/src/main/res/values/colors.xml`
- `app/src/main/res/values/themes.xml`

## Notă

Aceste fișiere reprezintă un mockup inițial de interfață pentru proiectul AlbOS; pot fi folosite ca bază de început pentru un build Android real.
